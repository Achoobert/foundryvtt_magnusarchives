# AGENTS.md

Foundry VTT v14 game system for Cypher V2 (Magnus Archives). TypeScript, built with Vite.

## Tooling

- Package manager: pnpm (see `packageManager` in `package.json`). Node >= 22.13.
- Install: `pnpm install`

## Checks

Run before calling a change done:

```bash
pnpm typecheck   # tsc --noEmit
pnpm test        # vitest
pnpm build       # vite build + pack import
```

`pnpm check` runs all three.

`pnpm test:e2e` (Cypress + Quench) needs a live Foundry instance and a configured
`fvtt.config.js`. It will not run in CI or a headless agent sandbox. Do not try to
fake it; say it was not run.

## Conventions

- Source lives in `src/`, templates in `templates/`, styles in `styles/`, translations in `lang/`.
- Compendium packs in `packs/` are generated by the `import:*` scripts. Do not hand-edit them.
